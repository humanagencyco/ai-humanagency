Setup

Set up Claude, your way

Three ways to get Claude working on your own files. About 5 minutes each. Pick one: you can always add the others later.

🖥️Desktop appNo terminal. Easiest to start.💻TerminalOne command. Best for developers.🧩VS CodeInside your code editor.

🖥️ Desktop app

1

Download the Claude app

Get Claude for Mac or Windows from claude.com/download and install it like any other app.

2

Sign in

Use the same account as claude.ai. Chatting works on the free plan. Claude Code inside the app needs a paid plan (Pro, Max, Team or Enterprise).

3

Point it at a folder

Open Claude Code in the app and choose a project folder. A new empty folder is fine for a first try.

4

Ask for something small

Type a request in plain English, for example: "Create a simple web page that says hello." Claude shows each change and asks before saving it, so you stay in control.

💻 Terminal

1

Check what you need

A Mac, Linux or Windows computer, a paid Claude plan or an Anthropic Console account, and a project folder. You don't need to install anything else first.

2

Install Claude Code

Mac, Linux or WSL:

curl -fsSL https://claude.ai/install.sh | bash

Windows (PowerShell):

irm https://claude.ai/install.ps1 | iex

On a Mac with Homebrew, brew install --cask claude-code also works.

It didn't work

See the official install troubleshooting page. If you installed with npm before, run claude install to switch to the native version, and never use sudo with npm.

3

Check it installed

Open a new terminal window and run this. You should see a version number.

claude --version
command not found: claude

Close the terminal and open a new one. Still failing? Run claude doctor.

4

Start it and sign in

Go to your project folder and start Claude Code. The first time, it opens your browser to sign in.

cd your-project-folder
claude

Type /login later to switch accounts. If the browser doesn't open, copy the link from the terminal.

5

Your first task

Type a request in plain English, such as "Create a hello world script in Python". Claude Code asks before it changes files or runs commands. Type /help to see more. For a quick one-off question:

claude -p "What is an LLM?"

🧩 VS Code

1

Install VS Code

Download it from code.visualstudio.com if you don't have it. JetBrains editors have a Claude Code plugin too.

2

Add the Claude Code extension

Open the Extensions panel (Cmd+Shift+X on Mac, Ctrl+Shift+X on Windows), search for Claude Code and install the one published by Anthropic.

3

Sign in

Use your Claude account (needs a paid plan), or an API key from console.anthropic.com, which is billed per use.

4

Try it on a small task

Open the Claude Code panel and ask: "Create a hello world script in Python." It shows each change before saving, so you can approve or reject it.

Nothing happens

Check the extension is installed and enabled, and that you're signed in to the account you meant to use.

Common questions

Do I need to pay?

Chatting with Claude is free. Claude Code needs a paid Claude plan (Pro, Max, Team or Enterprise) or an Anthropic Console account billed per use. Check claude.com/pricing for current prices.

Which one should I start with?

Never used a terminal? The desktop app. Already code? The terminal or VS Code.

Does it work on my computer?

Yes, on Mac, Windows and Linux. The desktop app is Mac and Windows only.

I'm stuck

Each step has a fix for the common errors. Still stuck? Email vikram@humanagency.co with the error and which setup you were following.
